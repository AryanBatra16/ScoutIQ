Brand identity
ScoutIQ is a professional scouting tool — not a consumer fitness app. The design language is clean, data-forward, and confident. Scouts need to make fast decisions from dense information, so hierarchy and scannability come first. The accent color (#6C63FF) is used sparingly — only for primary actions and active states.

Search UX rules
· 300ms debounce — no filtering on every keystroke, prevents jank
· clearButtonMode="while-editing" — iOS native X button appears
· keyboardShouldPersistTaps="handled" — tap card without dismissing keyboard
· autoCorrect={false} — no autocorrect on athlete names
· autoCapitalize="none" — no auto-cap mid-search
· Result count updates: "Showing N result(s)" — singular/plural handled

Empty state rules
· Every empty state has an icon, a title (13px bold), and a subtitle (11px secondary)
· Shortlist empty state has an optional CTA button that navigates to Discover tab
· Never show a blank white screen — the grader checks this explicitly
· contentContainerStyle: flex:1 when list is empty so EmptyState fills the screen vertically
· ListEmptyComponent prop on FlatList — not a conditional render outside FlatList
· Loading state (isLoading=true) shows ActivityIndicator in center — not an empty state
