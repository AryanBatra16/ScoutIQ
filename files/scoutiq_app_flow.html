    Toast (optional feature)

    Animated View slides up from bottom on toggle, shows "Added to shortlist ✓" or "Removed from shortlist". setTimeout(dismiss, 2000). Built with Animated.spring — no library.

    Back navigation

    5 · Shortlist screen
    Shortlist 25 pts
  • Stats bar: total athletes + avg score (recalculates live)
  • FlatList of shortlisted athletes
  • Swipe-to-delete via Swipeable (gesture-handler)
  • Persisted via AsyncStorage — survives restarts
  • Polished empty state when list is empty

    • Stats bar calculation

    avgScore = Math.round(shortlist.reduce((s,a) => s+a.score, 0) / shortlist.length)
    Both values recalculate on every add/remove.

    Swipe-to-delete mechanics

    Swipeable wraps each AthleteCard. renderRightActions returns a red "Remove" panel (width 80px). overshootRight=false prevents rubber-band. Pressing panel calls removeFromShortlist(id) which updates state + AsyncStorage.

    6 · Shared state flows
    useShortlist hook
    Single instance in AppNavigator. shortlist, isShortlisted, toggleShortlist, removeFromShortlist, isLoading passed as props to all screens.
    useDebounce hook
    Local to DiscoverScreen. 300ms delay on search text. Returns debouncedSearch used in useMemo filter. Cleanup clears timer on each keystroke.
    7 · AsyncStorage lifecycle
    Launch
    getItem('@scoutiq_shortlist')isLoading = true. Parse JSON → setShortlist. isLoading = false. Tab badge appears.
    Add
    toggleShortlist(athlete)State updates immediately (optimistic). setItem fires async. Button changes to "Remove". Badge count +1. Toast shows.
    Remove
    removeFromShortlist(id)Filter state. setItem with updated array. Swipeable collapses. Avg score recalculates. Toast shows.
    Restart
    getItem again on mountShortlist rehydrates from storage. Grader verifies this — test at Hour 9, not Hour 23.
    8 · Edge cases & states
    Search + filter = 0 results
    EmptyState: "No athletes found" · "Try a different name or change the sport filter"
    Empty shortlist
    EmptyState: 🏆 icon · "No athletes shortlisted" · optional CTA to Discover tab
    App restart
    AsyncStorage rehydrates shortlist. isLoading shows ActivityIndicator on Shortlist tab until resolved.
    Remove in Shortlist → open Profile
    Profile button shows "Add to Shortlist" — hook state is live, never stale. Works because hook is single instance.
    Single result count
    "Showing 1 result" — not "1 results". Handled by: result${n !== 1 ? 's' : ''}
    Android swipe gestures
    GestureHandlerRootView with flex:1 must wrap everything in App.tsx. Without it, swipe silently fails on Android only.
